# ⚽ 축구 선수 랜덤 디펜스 (FPRD)

「랜덤 과학 인물 디펜스」를 모티브로, **The Guardian이 선정한 2025 세계 축구 선수 TOP 50**을 영입해 원정 군단을 막아내는 랜덤 디펜스 게임입니다.

## 실행 방법

빌드 과정이 없습니다. 둘 중 하나를 쓰면 됩니다.

1. `index.html`을 브라우저로 바로 엽니다(더블클릭).
2. 로컬 서버로 엽니다(권장).
   ```bash
   python -m http.server 8765
   ```
   서버를 띄운 뒤 브라우저에서 `http://localhost:8765` 에 접속합니다.

진행 상황(도감·기록·트로피·진행 중 경기)은 브라우저 `localStorage`에 저장됩니다.

## 선수 특징 → 스킬

모든 선수는 네 층의 능력을 가집니다.

- **기본 공격(포지션)**: 피니셔(장거리 단일), 박스 스트라이커(근거리 광역), 중거리 슈터, 드리블러(고속 단일), 플레이메이커(연쇄 패스), 중원 사령관, 수비수(광역 제어), 윙백(직선 관통), 골키퍼(넓은 범위 제어).
- **플레이 스타일(13종)**: 결정력, 드리블, 스피드, 패스, 강슛, 제공권, 태클, 압박, 체력, 리더십, 빅게임, 선방, 세트피스.
- **확률 스킬**: 선수마다 실제 커리어를 반영한 고유 기술입니다. 예) 레반도프스키 「9분 5골」, 벨링엄 「추가시간 바이시클킥」, 라이스 「직접 프리킥」, 쿠르투아 「UCL 결승 선방쇼」.
- **패시브(전설 이상)**: 예) 뎀벨레 「양발잡이」는 모든 공격이 두 번 적중합니다. 케인 「어시스트 마스터」, 크바라츠헬리아 「크바라도나」, 메시 「GOAT」는 팀 전체 버프, 마라도나 「신의 손」은 방어 무시, 베켄바우어 「카이저 리베로」.

## 게임 규칙

원작 규칙을 그대로 가져왔습니다.

- **영입**: 45골드 또는 영입권. 확률은 노멀 49.9 / 레어 28 / 유니크 14 / 에픽 6 / 전설 1.57 / 신화 0.43 / 초월 0.1%, **히든 0.03%**입니다(트로피 「레전드 매치 초대장」 보너스 포함 최대 0.06%). 지정 영입은 전설 등급 선택, 3,000골드입니다.
- **합성**: 에픽 이하의 같은 선수 3명을 한 단계 위 등급의 무작위 선수로 바꿉니다.
- **조합**: 신화 = 전설 3명, 초월 = 신화 2명 + 전설 1명, 태초 = 초월 2명 + 신화 2명. 재료는 소속팀·대표팀 인연으로 구성했습니다.
- **히든 비밀 조합**: 히든 레전드 5인마다 재료가 정해진 비밀 조합이 있습니다. **힌트는 제공하지 않으며**, 알맞은 선수들이 경기장에 모이면 「조합 가능」에 나타나고 그때 발견 처리됩니다.
- **등급 강화, 등급 일괄 판매, 자동 판매, 잠금, 드래그 배치**를 지원합니다.
- **패배 조건**: 경기장의 적이 150명을 넘거나, 보스(5웨이브마다 등장)를 120초 안에 처치하지 못하면 패배합니다.
- **정규 40웨이브를 클리어하면 무한 모드**가 열립니다.
- 긴급 임무(40종)와 연승 보상, 돌발 상황, 3웨이브마다 경기 이벤트가 있습니다.
- **트로피 캐비닛(원작의 유물)**: 웨이브를 클리어할 때마다 토큰을 받아 트로피 34종을 뽑고 강화합니다. 효과는 다음 경기부터 영구 적용됩니다.
- **선수 도감, 기록실(로컬 랭킹·업적), 이어하기(자동 저장)**를 지원합니다.

**단축키**: Q 영입 · W 10회 영입 · E 합성 · R 조합 · U 강화 · 1/2/3 배속 · Space 일시정지 · S 판매 · L 잠금 · M 선택 선수 합성 · Esc 메뉴

## 축구 테마 배경

- 야간 경기장입니다. 관중석(점묘), 조명탑, LED 광고판, 타탄 트랙, 잔디 줄무늬 피치와 실제 비율의 라인·골대를 그렸습니다.
- 적(원정 군단)은 피치를 둘러싼 트랙을 돌고, 선수는 피치 위 48칸에 배치합니다. 공격할 때마다 **축구공**이 날아갑니다.
- **선수 강조(기본 켜짐)**: 잔디를 야간 톤으로 낮추고 배치칸을 어두운 전술판 타일로 그리며, 선수 초상에 어두운 외곽 테두리와 등급 색 글로를 둘러 잔디 위에서도 잘 보입니다. 적 토큰에도 밝은 테두리를 넣었습니다. 설정에서 끌 수 있습니다.
- **알림 정리**: 중요한 알림만 경기장 하단에 최대 3개(모바일 2개) 표시하고, 같은 알림은 ×n으로 합칩니다. 나머지 소식은 좌측 「경기 로그」에 기록합니다. 10회 영입·일괄 합성은 요약 1개와 최고 등급 연출 1개만 보여 줍니다.
- 보스: 철벽 센터백 / 레드카드 심판(선수 퇴장) / VAR 판독실(보호막) / 역습의 제왕(순간 질주) / 월드 올스타 FC

## 렌더링 최적화

- **2레이어 캔버스**: 경기장처럼 변하지 않는 배경은 리사이즈할 때만 한 번 그리고, 매 프레임에는 동적 요소만 그립니다.
- **스프라이트 캐시**: 선수 원형 초상·등급 링·포지션 배지, 적 토큰, 축구공을 오프스크린 캔버스에 미리 그려 두고 `drawImage`만 합니다.
- **오브젝트 풀**: 투사체 180개, 이펙트 160개, 피해 숫자 70개로 고정해 GC 부담이 없습니다. 피해 숫자는 프레임당 최대 6개까지만 새로 만듭니다.
- **고정 스텝 시뮬레이션**(1/60초)과 rAF 렌더링을 분리했고, 배속은 스텝 수로 처리합니다. 위치 계산은 경로 룩업 테이블로 O(1)이며, 죽은 적은 제자리 압축으로 제거합니다.
- **DOM 갱신 스로틀**: HUD 10Hz, 패널 4Hz이며 더티 체크로 바뀐 값만 반영합니다.
- **자동 품질 조절**: 평균 프레임이 느려지면 이펙트·DPR을 단계적으로 낮춥니다(설정에서 수동 선택 가능).
- 측정(선수 48명 + 적 150명): 시뮬레이션 약 0.07ms, 렌더 약 0.4ms/프레임입니다.

## 밸런스 검증

```bash
node tools/sim.js 5 normal
```

사람의 일반적인 운영(빈칸은 영입, 칸이 차면 강화, 골드가 남으면 하위 등급을 팔고 재영입)을 흉내 낸 봇으로 난이도별 도달 웨이브를 측정합니다. 원작의 적 체력 곡선을 그대로 쓰면 50인 로스터에서는 상위 등급 조합이 쉽게 모여 지옥 난이도까지 쉽게 클리어됐습니다. 그래서 후반 체력 곡선과 난이도 배율을 다시 보정했습니다. 히든 영입률을 0.03%로 낮춘 뒤 30~40웨이브 기준점을 한 번 더 조정했고, 현재 봇 기준 클리어율(10판)은 쉬움 9/10, 보통 6/10, 어려움 2/10, 지옥 0/10(중앙값 35웨이브)입니다.
