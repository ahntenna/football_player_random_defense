# ⚽ 축구 선수 랜덤 디펜스 (FPRD)

「랜덤 과학 인물 디펜스」를 모티브로, **The Guardian이 선정한 2025 세계 축구 선수 TOP 50**을 영입하고 **역대 레전드 18인**을 조합해 원정 군단을 막아내는 랜덤 디펜스 게임입니다.

현재 버전: **v1.9.0** (타이틀 화면 상단에 표시, `js/data/config.js`의 `F.VERSION`)

## 실행 방법

빌드 과정이 없습니다. 둘 중 하나를 쓰면 됩니다.

1. `index.html`을 브라우저로 바로 엽니다(더블클릭).
2. 로컬 서버로 엽니다(권장).
   ```bash
   python -m http.server 8765
   ```
   서버를 띄운 뒤 브라우저에서 `http://localhost:8765` 에 접속합니다.

진행 상황(도감·기록·트로피·진행 중 경기)은 브라우저 `localStorage`에 저장됩니다.

## 게임 규칙

원작 규칙을 그대로 가져왔습니다.

- **영입**: 45골드 또는 영입권. 확률은 노멀 49.9 / 레어 28 / 유니크 14 / 에픽 6 / 전설 1.57 / 신화 0.43 / 초월 0.1%입니다. 지정 영입은 전설 등급 선택, 3,000골드입니다. **영입 1회 · 영입 10회 버튼을 길게 누르고 있으면 2초마다 자동으로 반복 영입**합니다(버튼 아래 게이지로 다음 영입까지 남은 시간 표시). 초월(0.1%)에 당첨되면 초월 레전드 7인 중 1명이 나옵니다. **태초와 히든은 영입으로 나오지 않습니다(조합으로만 획득).**
- **합성**: 에픽 이하의 같은 선수 3명을 한 단계 위 등급의 무작위 선수로 바꿉니다.
- **조합**: 신화 = 전설 3명, 초월(레전드) = 신화 2명 + 전설 1명, 태초(레전드) = 초월 2명 + 신화 2명(일부는 인연 있는 하위 선수 1명 추가). 재료는 포지션 계보 · 소속팀 · 대표팀 인연으로 구성했습니다. 예) 크루이프 = 사비 + 이니에스타 + 야말 + 비티냐(바르사 티키타카 계보), 뮐러 = 반 바스텐 + 호나우두 + 케인 + 홀란 + 레반도프스키(바이에른 골잡이 계보).
- **히든 비밀 조합**: 히든 4인마다 재료가 정해진 비밀 조합이 있습니다(레전드가 재료에 포함됩니다). **힌트는 제공하지 않으며**, 알맞은 선수들이 경기장에 모이면 「조합 가능」에 나타나고 그때 발견 처리됩니다.
- **등급 강화, 등급 일괄 판매, 자동 판매, 잠금, 드래그 배치**를 지원합니다.
- **배치 순서**: 영입한 선수는 PC(가로 경기장)에서 맨 윗줄 · 맨 왼쪽 칸부터 오른쪽으로 차례로 채워집니다. 모바일(세로 경기장)은 같은 순서를 90° 돌린 것이라 **맨 오른쪽 위 칸에서 시작해 아래로** 채우고, 한 열이 차면 왼쪽 열로 넘어갑니다.
- **자동 일시정지**: 등급 판매 창, 조합 창, 전설 이상 선수 판매 확인창, 메뉴가 열려 있는 동안 경기가 멈추고 닫으면 재개됩니다(PC · 모바일 동일). 창을 열기 전에 직접 일시정지해 뒀다면 닫아도 정지 상태가 유지됩니다.
- **패배 조건**: 경기장의 적이 150명을 넘거나, 보스(5웨이브마다 등장)를 120초 안에 처치하지 못하면 패배합니다.
- **정규 40웨이브를 클리어하면 무한 모드**가 열립니다.
- 긴급 임무(40종)와 연승 보상, 돌발 상황, 3웨이브마다 경기 이벤트가 있습니다.
- **트로피 캐비닛(원작의 유물)**: 웨이브를 클리어할 때마다 토큰을 받아 트로피 34종을 뽑고 강화합니다. v1.9.0부터 웨이브 클리어 토큰 획득량이 30% 늘었습니다(`C.RELIC_TOKEN_BONUS`). 효과는 다음 경기부터 영구 적용됩니다.
- **선수 도감, 기록실(로컬 랭킹·업적), 이어하기(자동 저장)**를 지원합니다.

**단축키**: Q 영입 · W 10회 영입 · **Shift+W 지정 영입 · S 등급 판매** · E 합성 · **F 등급 강화 · R 조합하기** · 1/2/3 배속 · Space 일시정지 · Esc 메뉴 / 선택한 선수: Delete 판매 · L 잠금 · M 합성. PC에서는 하단 버튼 오른쪽 위에 단축키가 표시되며, 한글 입력 상태에서도 동작합니다(물리 키 기준).

## 축구 테마 배경

- 야간 경기장입니다. 관중석(점묘), 조명탑, LED 광고판, 타탄 트랙, 잔디 줄무늬 피치와 실제 비율의 라인·골대를 그렸습니다.
- 적(원정 군단)은 피치를 둘러싼 트랙을 돌고, 선수는 피치 위 48칸에 배치합니다. 공격할 때마다 **축구공**이 날아갑니다.
- **선수 카드**: 카드는 **배치칸 테두리에 꼭 맞는 크기**로 모든 선수가 같습니다. 등급 색 테두리 안쪽을 위 **사진 영역 72%** · 아래 **이름표 영역 28%**로 고정 분할하므로 이름 길이에 따라 크기가 달라지지 않습니다. 이름표에 전체 이름이 들어가면 전체 이름, 넘치면 대표 이름(성 또는 이름으로 더 알려진 쪽, `js/data/players.js`의 `short`), 그래도 넘치면 글자만 줄입니다. 포지션은 선수 정보 카드와 도감에서 볼 수 있습니다. **히든은 회전하는 무지개(프리즘) 테두리와 무지개 이름표·태그**로 표시해 전설(금색)과 구분됩니다.
- **모바일 · 태블릿 세로(폭 960px 이하)**: 스크롤 없는 앱형 화면입니다. HUD 한 줄, 경기장, 「📋 임무 / 📊 정보」 띠(탭하면 서랍으로 열림), 2줄 액션바로 구성됩니다. 세로 화면에서는 **경기장을 90° 돌려** 화면을 꽉 채우므로 선수가 약 45% 커집니다. 선수를 탭하면 **정보 카드가 경기장 위에 뜨는데**, 선수가 아래쪽에 있으면 위에, 위쪽에 있으면 아래에 표시해 선수를 가리지 않습니다. 배속은 버튼 하나로 1×→2×→3× 순환합니다. 정보 카드는 일반 탭에서만 열리고, 드래그로 선수를 옮길 때는 열리지 않습니다. 빠르게 두 번 탭해도 화면이 확대되지 않습니다(`touch-action: manipulation`).
- **선수 강조(기본 켜짐)**: 잔디를 야간 톤으로 낮추고 배치칸을 어두운 전술판 타일로 그리며, 선수 초상에 어두운 외곽 테두리와 등급 색 글로를 둘러 잔디 위에서도 잘 보입니다. 적 토큰에도 밝은 테두리를 넣었습니다. 설정에서 끌 수 있습니다.
- **알림 정리**: 중요한 알림만 경기장 하단에 최대 3개(모바일 2개) 표시하고, 같은 알림은 ×n으로 합칩니다. 나머지 소식은 좌측 「경기 로그」에 기록합니다. 10회 영입·일괄 합성은 요약 1개와 최고 등급 연출 1개만 보여 줍니다.
- 보스: 철벽 센터백 / 레드카드 심판(선수 퇴장) / VAR 판독실(보호막) / 역습의 제왕(순간 질주) / 월드 올스타 FC

## 렌더링 최적화

- **2레이어 캔버스**: 경기장처럼 변하지 않는 배경은 리사이즈할 때만 한 번 그리고, 매 프레임에는 동적 요소만 그립니다.
- **스프라이트 캐시**: 선수 원형 초상·등급 링·포지션 배지, 적 토큰, 축구공을 오프스크린 캔버스에 미리 그려 두고 `drawImage`만 합니다.
- **오브젝트 풀**: 투사체 180개, 이펙트 160개, 피해 숫자 70개로 고정해 GC 부담이 없습니다. 피해 숫자는 프레임당 최대 6개까지만 새로 만듭니다.
- **고정 스텝 시뮬레이션**(1/60초)과 rAF 렌더링을 분리했고, 배속은 스텝 수로 처리합니다. 위치 계산은 경로 룩업 테이블로 O(1)이며, 죽은 적은 제자리 압축으로 제거합니다.
- **DOM 갱신 스로틀**: HUD 10Hz, 패널 4Hz이며 더티 체크로 바뀐 값만 반영합니다.
- **자동 품질 조절**: 평균 프레임이 느려지면 이펙트·DPR을 단계적으로 낮춥니다(설정에서 수동 선택 가능).
- 측정(선수 48명 + 적 150명): 시뮬레이션 약 0.07ms, 렌더 약 0.4ms/프레임입니다.

## 밸런스 검증

```bash
node tools/sim.js 5 normal
```

사람의 일반적인 운영(빈칸은 영입, 칸이 차면 강화, 골드가 남으면 하위 등급을 팔고 재영입)을 흉내 낸 봇으로 난이도별 도달 웨이브를 측정합니다. 원작의 적 체력 곡선을 그대로 쓰면 50인 로스터에서는 상위 등급 조합이 쉽게 모여 지옥 난이도까지 쉽게 클리어됐습니다. 그래서 후반 체력 곡선과 난이도 배율을 다시 보정했습니다. 히든을 영입 대상에서 빼고, 초월·태초를 역대 레전드로 바꾼 로스터에 맞춰 30~40웨이브 기준점을 다시 조정했습니다. **v1.8.0에서는 난이도를 낮추기 위해 영입 확률은 그대로 두고 전 구간 적 체력만 약 35% 낮췄습니다**(1웨이브 260 → 170, 40웨이브 600만 → 390만). 현재 봇(트로피 효과 없음) 60판 기준 클리어율은 쉬움 98%(59/60), 보통 85%(51/60), 어려움 17%(10/60), 지옥 2%(1/60, 중앙값 35웨이브)입니다. 트로피 「레전드 매치 초대장」의 효과는 히든 영입 확률 대신 초월 영입 가중치(최대 +32.5%)로 바뀌었습니다.

## 사진 출처 · 라이선스

선수 사진 72장(현역 50 · 레전드 18 · 히든 4)은 모두 영문 위키백과 대표 이미지 중 **위키미디어 공용(Wikimedia Commons)의 자유 라이선스**(CC BY / CC BY-SA / CC0 / 퍼블릭 도메인) 이미지입니다. 얼굴 중심으로 잘라서(`js/data/photo-crops.js`) 사용했습니다. 선수별 저작자·라이선스·원본 링크는 게임의 **📷 사진 출처** 메뉴와 `js/data/photo-credits.js`에 있습니다. 사진을 다시 받으려면 `python tools/fetch_photos.py --force`를 실행하세요.
